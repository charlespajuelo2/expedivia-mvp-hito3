## 2. Reglas de uso

1. Solo se utiliza la base de conocimiento **aprobada y versionada**.
2. El sistema **no consulta normativa en Internet** de forma autónoma.
3. Cada criterio debe indicar su fuente y versión.
4. Si una fuente no tiene versión aprobada, el análisis se bloquea o se alerta antes de iniciar.
5. Si una fuente cambia después de una decisión, la evidencia se marca como **“fuente modificada”** y requiere revalidación.
6. Las ponderaciones deben sumar **100%** y estar aprobadas por el especialista.
7. El checklist oficial de 23 ítems reemplazará al subconjunto representativo de 7 ítems cuando esté disponible.
